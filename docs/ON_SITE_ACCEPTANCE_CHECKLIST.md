# happlayer 现场验收 Checklist（展项主机）

> 用途：开发机绿测只代表 RC。本清单在**目标展项主机**上逐项勾选，全绿才算 GA。
> 用法：每一项给出「怎么做 + 通过标准」，实测数据当场填进划线处。命令默认在
> 播放包目录（`...\build\Release\`，含 happlayer.exe / layers.txt / clips\ / *.dll）执行。
> 关联：`README.md`、`docs/USER_GUIDE.md`（含 2026-09-16 纠错记录）。

---

## 0. 主机环境（5 分钟）

- [ ] **VC++ 运行时**：纯净系统先装 VC++ 2015-2022 x64 Redistributable（缺则 DLL 加载失败）
- [ ] **显卡驱动**：N 卡驱动 521.xx+；设备管理器确认独显型号：____________
- [ ] **显示器拓扑**：接好全部屏幕，系统「显示设置」确认分辨率/排列与设计一致
- [ ] **电源**：高性能电源计划；笔记本必须接电源、独显直出（Optimus 混合输出有额外拷贝开销）
- [ ] **散热**：10 层 4K 以上需台式散热；记录主机形态：台式 / 笔记本 ____________

## 1. 部署包完整性

- [ ] 整个 `Release\` 目录已拷到主机（不是只拷 exe）
- [ ] 清点文件：`happlayer.exe`、9 个 FFmpeg `av*.dll` + `swscale/swresample`、
      `SDL2.dll`、`layers.txt`、`clips\*.mov`
- [ ] exe 与源码对齐：若到现场后重新编译过，确认 exe 时间戳晚于最后一次源码改动
      （交付前断档教训：曾出现源码 8-20、exe 停在 8-17）
- [ ] **压测素材**：4K bench 素材默认在开发机 `C:\hap4k_clips`，换机需一并拷贝，
      否则 bench4k/bench15*.txt 跑不了

## 2. 配置与素材

- [ ] `layers.txt` 内路径全部相对 exe 目录；每个 `[queue]` 至少一层不循环（否则永不切场，启动会警告）
- [ ] 逐文件核验编码/分辨率/帧率，逐行对一遍（不要复用"应该对"的旧判断）：
      ```
      ..\..\deps\ffmpeg\bin\ffprobe.exe -show_streams -show_format clips\<文件>.mov
      ```
      主力层应为 `codec_name=hap*`；记录每层分辨率/帧率：____________
- [ ] H.264/QTRLE 只出现在 1080p 以下点缀层
- [ ] 备用：故意把 layers.txt 改一个错路径 → 应**忽略本次变更继续播旧配置，不黑屏**（热重载兜底）

## 3. 基础播放

- [ ] 双击/命令启动，开场日志核对：显示器编号列表、`[NVDEC]` 是否启用、
      `回读策略=1`（Win11 直角生效）
- [ ] 各队列按设计入场/循环/播完退出/自动切场，末场回到第一场
- [ ] `fade>0` 时切场为黑场淡入淡出，无闪黑/花屏
- [ ] 自定义矩形层（`|x%|y%|宽%|音量%|`）位置、大小、音量正确
- [ ] 多源音频：BGM 与各层解说按设计混音，无削顶；长跑音画不漂移（±50ms 校正）
- [ ] 键盘：空格 / R / F / M / Esc 全部有效

## 4. 多屏拼接 / 无边框

- [ ] `[window] borderless=1`；跨屏总尺寸写对（如双 1080p 横屏 = `3840x1080`）
- [ ] `monitor=N` 与启动日志编号一致；`pos` 偏移正确
- [ ] 屏幕拼缝处画面连续，无白边/圆角（Win11 已强制直角，日志回读确认）
- [ ] `fullscreen=1` 占满目标显示器，size/pos 如设计失效

## 5. 性能长跑（验收核心，必须热机 + 跑满计划时长）

> 冷机数字不算数：开发机实测持续满载约 10 秒后降频，冷热差 2~3 倍。

- [ ] 短跑冒烟：`happlayer.exe layers.txt --bench 30 --json --port 0`，记录平均 fps：______
- [ ] **长跑**：按展项实际节目连续跑 **≥ 计划单次运行时长**（建议 ≥2 小时，7 天健康监控周期另测），
      中途分段记录 fps，重点看热机后稳态：______
- [ ] 稳态 fps 达到设计目标（经验红线：≤4~6 层 4K 或 10+ 层 1080p 才稳妥）
- [ ] 全程无冻屏、无声音中断、无内存/显存持续上涨
- [ ] 若不达标，按序处置：确认 NVDEC → `--max-fps 30` → 主力转 HAP → 减同时层数 → 拆队列
- [ ] 极端配置用 `bench15alpha.txt` / `bench15mix1080.txt` 摸上限（需对应素材）

## 6. 中控联调（UDP/OSC，默认端口 7000，绑定 0.0.0.0）

- [ ] 防火墙放行 7000/UDP；`netstat -ano | findstr :7000` 确认监听
- [ ] 文本命令逐条测（每条有回执）：play / pause / toggle / restart / next / prev /
      `queue 2` / `volume 0.5` / mute / `status` / quit
      ```
      python -c "import socket;s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM);s.sendto(b'status',('127.0.0.1',7000));print(s.recvfrom(4096))"
      ```
- [ ] 中控实机（非本机）按展项 IP 发 OSC：`/queue`(int)、`/volume`(float) 等 7 条地址全通；
      测一条 `#bundle`
- [ ] `status` 回执的队列号/时间/fps/各层状态与画面对得上
- [ ] 不需要网络控制时用 `--port 0` 关闭，复测正常

## 7. 开机自启 / 防休眠 / 健康监控

- [ ] 以**将用于展项的 Windows 账户**登录，跑 `scripts\set-config.bat` 设 exe/配置路径并选自启安装
- [ ] 重启主机 → 自动起播，画面/声音/屏位正确
- [ ] 注册表核对：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\happlayer`
- [ ] 播放期间系统不睡眠、显示器不关（已内置 ES_DISPLAY_REQUIRED）
- [ ] 健康监控演练：制造持续低帧（或临时 `--max-fps` 压低）确认 fps<5 持续 5s 会自动退出，
      由外部（任务计划/自启）重新拉起成功
- [ ] 窗口位置记忆：正常退出后 `%APPDATA%\happlayer\state.json` 记录，重启不污染全屏配置
- [ ] `scripts\uninstall-autostart.bat` 可干净移除（撤场验证）

## 8. 异常演练（现场改错不翻车）

- [ ] 热重载中途改错 layers.txt → 忽略错误配置、继续旧节目、不黑屏
- [ ] 拔掉/移走某素材 → 看日志报错方式，确认不影响其他层与切场
- [ ] 断网启动（依赖全本地，不应受影响；OSC 仅在有中控时需要网络）
- [ ] 进程崩溃后能否被自动拉起恢复播放
- [ ] （可选）Vulkan 路径：仅当现场 OpenGL 不达标才试 `HAPPLAYER_USE_VULKAN=1`，
      先在测试机验证——init 失败会直接退出、不回退 GL，**勿在开展当天首次启用**
